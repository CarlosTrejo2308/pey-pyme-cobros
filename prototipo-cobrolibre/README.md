# Prototipo CobroLibre (HTML, CSS y JS)

Prototipo estático de la interfaz: registro de PyME, cobros con QR y WhatsApp, cobros recurrentes con autorización del cliente y asistente por voz o texto con diseño accesible para personas mayores.

Abre `index.html` en el navegador. No requiere instalación.

**Es una simulación:** el QR, los pagos y las autorizaciones no son reales.
